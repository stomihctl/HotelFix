# HotelFix

Android app for reporting and managing maintenance faults in a hotel. Guests report a fault from their room by scanning a QR code, managers assign it to a technician, and everyone follows the ticket until it is closed.

Built as my BSc thesis at the School of Electrical Engineering, University of Belgrade (2026).

## Roles

| Role | Sign-in | What they do |
| --- | --- | --- |
| Guest | None, scans the room QR code | Reports a fault, follows its status, chats with the manager, confirms the fix |
| Manager | Email and password | Reviews reports, assigns technicians, generates room QR codes, views statistics |
| Technician | Email and password | Accepts or rejects assigned work, updates progress, marks it finished |

Manager and technician accounts are created administratively. There is no self-registration.

## Features

- **Fault reporting by QR code.** Each room has a QR token generated by the manager. The guest scans it, fills in type, description and urgency, and can attach a photo taken with the camera.
- **Ticket lifecycle.** Reported → Assigned → Accepted → In progress → Finished → Closed. The guest confirms the fix to close the ticket, and the manager can reassign it if the guest says it is still broken.
- **Rejection with a reason.** A technician can reject an assignment with a required explanation, which returns the ticket to the manager.
- **Assignment suggestions.** The technician list is sorted by specialization match and by current number of active tickets.
- **Real-time chat** between guest and manager for each ticket, locked once the ticket is closed.
- **Notifications** for new reports, status changes, new assignments and chat messages.
- **Statistics.** Pie charts by fault type and by technician and a bar chart by day, with export to PDF.
- **QR management.** The manager generates and deactivates room QR codes and exports them to PDF for printing.

## Tech stack

- Kotlin, Jetpack Compose, MVVM
- Navigation Compose, single-activity architecture
- Firebase Firestore and Firebase Authentication
- ZXing for QR generation and scanning
- Android `PdfDocument` and Canvas for PDF export; charts drawn directly on Compose Canvas, with no charting library

## Running the project

1. Clone the repository and open it in Android Studio.
2. Create a Firebase project, enable Firestore and Email/Password authentication, and add an Android app with the package name `com.example.myapplication`.
3. Download `google-services.json` from the Firebase console and place it in the `app/` folder.
4. Create manager and technician accounts in Firebase Authentication.
5. Run the app on a device or emulator.

## Known limitations

- Notifications are raised locally from Firestore listeners, not through Firebase Cloud Messaging, so they arrive only while the app process is alive.
- Photos are stored as compressed Base64 strings in Firestore instead of Firebase Storage.
- The system is designed for a single hotel.
